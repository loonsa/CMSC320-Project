Introduction¶

Our topic is analyzing a Spotify dataset. We chose this dataset because it is highly relevant to our age bracket as college students, as most of us are avid music listeners that use Spotify to stream music. The data itself is especially interesting due to its sheer volume: there are over 900 unique songs with 24 different metrics for each song, giving more than enough data to draw interesting conclusions and discover what is popular on Spotify. For instance, we can determine which artist is releasing the most songs that end up in the highest number of playlists, or which songs are getting the most streams and why they might be more popular than others. Some questions we are posing:

  • What makes a song popular?
  • What is the definition of popular?
  • Can we identify characteristics of a song that will make it popular?

From a college student perspective, answering these questions will do little to benefit our lives. However, it'll be fun to know why some songs are more popular than others- when a tune comes up, we can listen for those features.

Basic Data Exploration and Summary of Statistics¶

First method: Hypothesis Test (T-Test)

  1. This test will determine if there is a statistically significant difference in the mean danceability between "Popular" songs and "Less Popular" songs.
  2. To create these two groups, first find the median value of the streams column.
  • Songs with streams above the median will be classified as "Popular."
  • Songs with streams at or below the median will be classified as "Less Popular."
  1. Hypotheses: -Null Hypothesis: There is no difference in the average danceability between the "Popular" and "Less Popular" groups. -Alternative Hypothesis: There is a difference in the average danceability between the two groups.
  2. If the p-value is less than 0.05, we will reject the null hypothesis and conclude that the difference in danceability is statistically significant

Second Method: Hypothesis Test (Chi-Squared Test)

  1. This test will determine if there is a statistically significant relationship between the music platform (Apple vs. Spotify) and a song’s popularity category ("Popular" or "Less Popular").

  2. To create these two groups, we will classify songs based on the median value of the streams column from our data:

    • Songs with streams above the median will be labeled "Popular".
    • Songs with streams at or below the median will be labeled "Less Popular".

  3. Hypotheses:

    • Null Hypothesis (H₀): There is no relationship between platform type and song popularity.
    • Alternative Hypothesis (H₁): There is a relationship between platform type and song popularity.

  4. If the p-value is less than 0.05, we will reject the null hypothesis and conclude that there is a statistically significant relationship between platform type and song popularity.

Third Method: Relationship between Continuous Variables (Pearson's Correlation Test)

  1. This method will investigate whether there is a linear correlation between "streams" and and a number of metrics for each song which include "danceability, energy, liveness, and acousticness.

  2. To accomplish this Pearson's correlation test will be run between each "bpm" value and the corresponding "danceability" value. Pearson's test is being used because streams and the metrics are all continuous variables.

  3. First Some Spotify themed scatter plots will be created to help visualize the relationship between each pair of variables.

  4. Then the Pearson Correlation test will be run. This test will return a correlation coefficient "r". For the correlation coefficient, a value of 1 indicates a perfect positive linear relationship (perfectly correlated), -1 indicates a perfect negative linear relationship (perfectly anti-correlated), and 0 indicates no linear relationship. So, r values closer to 1 or -1 will help us determine if there are strong relationships any of the variable pairs.

first you'll want to import pearsonr from the scipy.stats library. Scipy is a Python library with lots of useful code already written for others to use. We're taking from the "stats" sub library which contains lots of functions that make running statistical tests on data very simple. Pearsonr will let us run Pearson's Correlation Test on our data with ease. For further reading see: https://docs.scipy.org/doc/scipy/reference/stats.html

Primary Analysis¶

Based on the previous exploratory data analysis- especially the last one, correlating danceability, energy, liveness, and accousticness- there unfortunately seems to be little correlation between what a song "sounds" like and how popular it is, based on number of streams.
In the next section, we'll train learning models on predicting the number of streams a song has based on how many playlists it is in.

Insights and Conclusions¶

From our analysis, we found that a song’s audio features do not strongly relate to its popularity. To elaborate, we used a t-test to compare the mean danceability of more popular and less popular songs, and the result showed no significant difference, which matched the boxplot where both groups shared almost identical distributions. Additionally, we ran correlation tests for danceability, energy, liveness, and acousticness against stream counts. The scatterplots supported the correlation results, since all four features showed very weak relationships with streams and no visible trend in any direction. Our heatmap comparing platform vs popularity group also confirmed that platform alone does not separate popular songs from less popular ones.

These findings were consistent with the performance of our audio-only machine learning models, which showed poor R² scores and struggled to learn any meaningful patterns. This supported the earlier statistical tests by showing that sound-based features alone cannot predict streaming success.

When we included playlist and chart information, model performance increased significantly. The model comparison chart showed R² values around 0.70 for all models, with Gradient Boosting performing the best. The feature importance plot showed that the number of Spotify playlists a track appears in was the most influential predictor, followed by Apple playlists and chart placements. The actual vs predicted plot and the residual plot confirmed that predictions became more stable and accurate once playlist visibility was included.

Overall, our results show that popularity is influenced far more by exposure than by musical characteristics. Playlist placement, chart presence, and overall visibility play a much larger role in driving streams than features like danceability or energy. Future work could include artist popularity, social media trends, or release timing to better understand other factors that contribute to a song becoming successful.
